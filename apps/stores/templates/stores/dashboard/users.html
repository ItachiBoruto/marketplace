Propietario Owner
Control total del comercio. Puede gestionar productos, pedidos, ver estadísticas, editar el perfil del comercio y configurar los datos de pago y delivery. Recomendado para el dueño o socio principal.
Ver dashboard Gestionar productos Aprobar/rechazar pedidos Marcar enviado Ver movimientos Editar perfil del comercio Configurar datos de pago
🛠
Gestor Manager
Puede gestionar el día a día del comercio: productos, pedidos y stock. No puede cambiar la configuración del comercio ni los datos de pago. Ideal para empleados de confianza o encargados.
Ver dashboard Gestionar productos Aprobar/rechazar pedidos Marcar enviado Ver movimientos Editar perfil del comercio Configurar datos de pago
👁
Visualizador Viewer
Solo puede ver la información del comercio. No puede modificar nada. Ideal para contadores, auditores o socios que solo supervisan.
Ver dashboard Gestionar productos Aprobar/rechazar pedidos Marcar enviado Ver movimientos Editar perfil del comercio Configurar datos de pago
⚠ Importante: solo el superadministrador puede asignar o cambiar roles. Asegúrate de dar el rol adecuado según el nivel de confianza.
